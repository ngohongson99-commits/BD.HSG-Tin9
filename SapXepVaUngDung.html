1. Bài toán mở đầu: mảng đếm tần suất

Đề bài. Cho n số nguyên, mỗi số nằm trong khoảng 0 … 1000. Tìm giá trị xuất hiện nhiều lần nhất và số lần xuất hiện của nó (nếu có nhiều giá trị cùng nhiều nhất, lấy giá trị nhỏ nhất).
Giới hạn: n ≤ 105.

Ví dụ: dãy 3 1 3 2 1 3 → giá trị 3, xuất hiện 3 lần.

Cách 1: với mỗi phần tử, đếm lại cả dãy

for (int i = 0; i < n; i++) {
    int c = 0;
    for (int j = 0; j < n; j++) if (a[j] == a[i]) c++;
    // so sánh c với kết quả tốt nhất...
}

Hai vòng lặp lồng nhau: n² = 1010 phép so sánh, quá chậm. Và ta đang đếm đi đếm lại cùng một giá trị nhiều lần.

Ý tưởng: "bảng điểm danh"

Vì giá trị chỉ từ 0 đến 1000, ta lập sẵn một bảng gồm 1001 ô: ô cnt[v] ghi số lần giá trị v đã xuất hiện. Đọc tới số nào thì tăng ô tương ứng thêm 1. Đây là "dùng giá trị làm chỉ số".

#include <iostream>
using namespace std;

const int M = 1000;
int cnt[M + 1];                 // toàn cục: tự động bằng 0

int main() {
    int n; cin >> n;
    for (int i = 0; i < n; i++) {
        int x; cin >> x;
        cnt[x]++;                   // điểm danh
    }
    int bestV = 0;
    for (int v = 1; v <= M; v++)
        if (cnt[v] > cnt[bestV]) bestV = v;   // ">" nên ưu tiên giá trị nhỏ
    cout << bestV << " " << cnt[bestV];
}

Chạy thử với 3 1 3 2 1 3: sau khi đọc xong, cnt[1] = 2, cnt[2] = 1, cnt[3] = 3, các ô khác bằng 0. Tìm ô lớn nhất: cnt[3] = 3 → in 3 3.

v01234…
cnt[v]02130…

Độ phức tạp: O(n + M): đọc n số, rồi quét M ô.

Điều kiện để dùng được: giá trị phải là số nguyên không âm và nhỏ (cỡ vài triệu trở xuống), vì giá trị chính là chỉ số mảng. Nếu có số âm, số rất lớn (như 109) hoặc là chuỗi thì cách này chưa dùng được; các cách thay thế sẽ nói ở mục 5 và ở chuyên đề sau.

2. Counting sort: sắp xếp mà không so sánh

Có bảng cnt rồi, ta đã biết mỗi giá trị xuất hiện bao nhiêu lần. Để in dãy đã sắp xếp tăng dần chỉ cần đi từ giá trị nhỏ đến lớn và in mỗi giá trị cnt[v] lần:

for (int v = 0; v <= M; v++)
    for (int k = 0; k < cnt[v]; k++)
        cout << v << " ";

Ví dụ dãy 4 2 2 8 3 3 1: cnt[1]=1, cnt[2]=2, cnt[3]=2, cnt[4]=1, cnt[8]=1 → in ra 1 2 2 3 3 4 8.

Độ phức tạp: O(n + M), không phải O(n log n). Khi giá trị nhỏ thì nhanh hơn sort. Đổi lại, nó tốn bộ nhớ M ô và chỉ dùng được với số nguyên trong khoảng nhỏ.

3. Hàm sort của C++

Với dữ liệu tổng quát (số âm, số lớn, số thực, chuỗi, …), ta dùng sort có sẵn trong <algorithm>, độ phức tạp O(n log n).

#include <algorithm>
#include <functional>

int a[5] = {5, 2, 9, 1, 7};
sort(a, a + 5);                              // mảng tĩnh → 1 2 5 7 9

vector<int> v = {5, 2, 9, 1, 7};
sort(v.begin(), v.end());                    // vector → tăng dần
sort(v.begin(), v.end(), greater<int>());   // giảm dần → 9 7 5 2 1

Cách đọc: sort(đầu, cuối) sắp xếp các phần tử từ vị trí đầu đến ngay trước cuối (nửa mở). Với mảng tĩnh a gồm n phần tử: sort(a, a + n). Nếu mảng đánh số từ 1: sort(a + 1, a + n + 1).

💡 Chọn công cụ: giá trị nhỏ, không âm → mảng đếm (counting sort) nhanh hơn. Còn lại → sort.

4. Sắp xếp theo tiêu chí riêng

Đôi khi "nhỏ hơn" không phải là so sánh số thông thường (ví dụ sắp học sinh theo điểm giảm dần). Ta đưa cho sort một hàm so sánh cmp(x, y): trả về true nếu x phải đứng trước y.

struct HS { string ten; int diem; };

vector<HS> ds = {{"An", 8}, {"Binh", 9}, {"Chi", 8}};
sort(ds.begin(), ds.end(), [](const HS &x, const HS &y) {
    if (x.diem != y.diem) return x.diem > y.diem;   // điểm cao đứng trước
    return x.ten < y.ten;                     // bằng điểm: tên theo thứ tự chữ cái
});
// kết quả: Binh 9, An 8, Chi 8

Với pair: mặc định sắp xếp theo thành phần thứ nhất, nếu bằng thì theo thành phần thứ hai.

vector<pair<int,int>> p = {{2, 5}, {1, 9}, {2, 3}};
sort(p.begin(), p.end());         // (1,9) (2,3) (2,5)
Quy tắc vàng: hàm so sánh phải dùng < hoặc >, không dùng <= hoặc >=. Hai phần tử bằng nhau thì cmp phải trả về false cả hai chiều, nếu không chương trình có thể lỗi hoặc sập.

5. Ứng dụng: sắp xếp rồi mới làm

Nhiều bài trở nên đơn giản khi dãy đã sắp xếp, vì các phần tử bằng nhau (hoặc gần nhau) đứng cạnh nhau.

Bài mẫu. Cho n số nguyên bất kỳ (có thể âm, có thể rất lớn). Kiểm tra dãy có hai phần tử trùng nhau hay không.
Ví dụ: 7 -3 9 7 2 → có trùng.

Thử mọi cặp thì O(n²). Nhưng nếu sắp xếp trước, mọi giá trị trùng nhau sẽ liền kề: -3 2 7 7 9. Chỉ cần so sánh các phần tử liền kề.

sort(a.begin(), a.end());
bool trung = false;
for (int i = 1; i < n; i++)
    if (a[i] == a[i - 1]) trung = true;
cout << (trung ? "CO" : "KHONG");

Tổng cộng O(n log n). Cách này dùng được cho số âm và số lớn, là những trường hợp mà mảng đếm ở mục 1 chưa xử lý được (Bài 5 bên dưới dùng đúng ý tưởng này để đếm tần suất).

6. Bài tập nâng dần

Với mỗi bài hãy tự hỏi: "giá trị nhỏ và không âm thì dùng mảng đếm được không? Hay cần sắp xếp? Tiêu chí so sánh là gì?"

Bài 1. Liệt kê giá trị và số lần xuất hiện (cơ bản, mảng đếm)

Cho n số nguyên trong khoảng 0 … 106. In mỗi giá trị xuất hiện kèm số lần, theo thứ tự giá trị tăng dần.
Ví dụ: 3 1 3 2 1 3 → 1 2, 2 1, 3 3 (mỗi cặp một dòng)

Xem lời giải

Hướng dẫn: đếm bằng cnt, rồi quét v từ 0 đến 106; ô nào lớn hơn 0 thì in. Quét theo thứ tự tăng của v nên kết quả tự động đã sắp xếp.

vector<int> cnt(1000001, 0);
for (int i = 0; i < n; i++) { int x; cin >> x; cnt[x]++; }
for (int v = 0; v <= 1000000; v++)
    if (cnt[v] > 0) cout << v << " " << cnt[v] << "\n";

Bài 2. Hai mảng có cùng các phần tử không? (dễ)

Cho hai mảng a và b cùng n phần tử. Hỏi b có phải là một cách sắp xếp lại các phần tử của a không? In YES hoặc NO.
Ví dụ: a = 1 2 3 2, b = 2 1 2 3 → YES

Xem lời giải

Hướng dẫn: nếu hai mảng chỉ khác thứ tự thì sau khi sắp xếp cả hai, chúng phải giống hệt nhau. Với vector, có thể so sánh trực tiếp bằng ==.

sort(a.begin(), a.end());
sort(b.begin(), b.end());
cout << (a == b ? "YES" : "NO");

Cách khác (khi giá trị nhỏ, không âm): đếm tần suất của hai mảng bằng hai mảng cnt rồi so sánh từng ô.

Bài 3. Tổng k số lớn nhất (dễ)

Cho n số và số k (k ≤ n). In tổng của k số lớn nhất.
Ví dụ: 5 1 9 3 7, k = 3 → 21 (9 + 7 + 5)

Xem lời giải

Hướng dẫn: sắp xếp giảm dần, rồi cộng k phần tử đầu.

sort(a.begin(), a.end(), greater<int>());
long long s = 0;
for (int i = 0; i < k; i++) s += a[i];
cout << s;

Bài 4. Xếp hạng học sinh (trung bình, hàm so sánh)

Cho n học sinh, mỗi học sinh gồm tên (không có khoảng trắng) và điểm. Sắp xếp theo điểm giảm dần, nếu bằng điểm thì theo tên tăng dần (thứ tự từ điển). In tên và điểm.
Ví dụ: An 8, Binh 9, Chi 8 → Binh 9, An 8, Chi 8

Xem lời giải

Hướng dẫn: dùng struct và hàm so sánh như mục 4: so điểm trước; nếu điểm khác nhau thì điểm cao đứng trước; nếu bằng thì so tên.

struct HS { string ten; int diem; };
vector<HS> ds(n);
for (auto &h : ds) cin >> h.ten >> h.diem;

sort(ds.begin(), ds.end(), [](const HS &x, const HS &y) {
    if (x.diem != y.diem) return x.diem > y.diem;
    return x.ten < y.ten;
});
for (auto &h : ds) cout << h.ten << " " << h.diem << "\n";

Bài 5. Giá trị xuất hiện nhiều nhất khi số có thể âm hoặc rất lớn (khá)

Giống bài mẫu mục 1, nhưng các số nằm trong khoảng −109 … 109 nên không dùng được mảng đếm. In giá trị xuất hiện nhiều nhất và số lần (nhiều giá trị cùng nhiều nhất thì lấy giá trị nhỏ nhất).
Ví dụ: -5 100000000 -5 7 -5 7 → -5 3

Xem lời giải

Hướng dẫn: sắp xếp, khi đó các giá trị bằng nhau đứng thành từng nhóm liên tiếp. Chỉ cần quét một lượt và đếm độ dài của từng nhóm: gặp phần tử bằng phần tử trước thì tăng độ dài nhóm hiện tại, ngược lại bắt đầu nhóm mới. Dùng điều kiện run > best (nghiêm ngặt) để nhóm có giá trị nhỏ hơn được ưu tiên khi bằng nhau.

sort(a.begin(), a.end());
int best = 1, run = 1; long long bestVal = a[0];
for (int i = 1; i < n; i++) {
    if (a[i] == a[i - 1]) run++;
    else run = 1;
    if (run > best) { best = run; bestVal = a[i]; }
}
cout << bestVal << " " << best;

Thời gian O(n log n). Đây là "bản thay thế" của mảng đếm khi giá trị quá lớn hoặc có số âm.

Bài 6. Chọn nhiều đoạn không giao nhau nhất (khó, sắp xếp rồi tham lam)

Cho n đoạn [l, r) (hai đoạn chỉ chạm nhau ở đầu mút, như [1,3) và [3,5), thì không giao nhau). Chọn nhiều nhất có thể các đoạn đôi một không giao nhau. In số đoạn tối đa.
Ví dụ: các đoạn (1,3), (2,5), (4,7), (6,8) → 2

Xem lời giải

Hướng dẫn: sắp xếp các đoạn theo điểm kết thúc tăng dần. Duyệt lần lượt: nếu đoạn hiện tại bắt đầu không sớm hơn điểm kết thúc của đoạn đã chọn gần nhất thì chọn nó. Lý do: đoạn kết thúc sớm nhất chừa ra nhiều chỗ nhất cho các đoạn sau, nên chọn nó không bao giờ làm đáp án tệ đi.

Mẹo: lưu mỗi đoạn dưới dạng pair(r, l) (kết thúc trước) thì sort mặc định đã sắp xếp theo điểm kết thúc.

#include <climits>
vector<pair<int,int>> seg(n);
for (int i = 0; i < n; i++) {
    int l, r; cin >> l >> r;
    seg[i] = {r, l};
}
sort(seg.begin(), seg.end());

int cnt = 0, last = INT_MIN;
for (auto &s : seg)
    if (s.second >= last) { cnt++; last = s.first; }
cout << cnt;

Chạy thử: sau sắp xếp theo kết thúc: (1,3) (2,5) (4,7) (6,8). Chọn (1,3), last = 3; bỏ (2,5) vì 2 < 3; chọn (4,7), last = 7; bỏ (6,8) vì 6 < 7 → 2.

7. Lưu ý và lỗi thường gặp

Mảng đếm quá nhỏ: nếu giá trị lớn nhất là M thì cnt phải có ít nhất M + 1 ô (chỉ số 0…M). Truy cập ngoài phạm vi gây lỗi khó tìm.
Mảng đếm với số âm hoặc số lớn: cnt[-5] là sai, cnt[1000000000] không đủ bộ nhớ. Hãy dùng sort (như Bài 5) hoặc các cấu trúc ở chuyên đề sau.
Sai khoảng trong sort: mảng đánh số từ 0 dùng sort(a, a + n), mảng đánh số từ 1 dùng sort(a + 1, a + n + 1).
Hàm so sánh dùng <=: phải dùng < hoặc > (xem mục 4).
Sắp xếp làm mất vị trí gốc: nếu đề hỏi chỉ số ban đầu, hãy lưu kèm chỉ số, ví dụ pair(giá trị, chỉ số). Khi cần giữ thứ tự ban đầu của các phần tử bằng nhau, dùng stable_sort.
Tóm tắt: giá trị nhỏ, không âm → mảng đếm (đếm tần suất, counting sort) ở O(n + M). Dữ liệu bất kỳ → sort ở O(n log n), kèm hàm so sánh khi cần tiêu chí riêng. Sắp xếp xong, các phần tử bằng nhau đứng cạnh nhau nên nhiều bài (trùng lặp, đếm nhóm, tham lam) trở nên dễ.
