👉👈 Hai con trỏ (Two Pointers)

Hai biến chỉ số cùng di chuyển để duyệt mảng chỉ một lượt, thay vì hai vòng lặp lồng nhau

1. Bài toán mở đầu2. Ý tưởng3. Cài đặt4. Chạy thử5. Cùng chiều6. Bài tập7. Lưu ý

1. Bài toán mở đầu

Đề bài. Cho dãy n số nguyên đã sắp xếp tăng dần và số K. Tìm hai vị trí i < j sao cho a[i] + a[j] = K. In cặp đó, hoặc NO nếu không có.
Giới hạn: n ≤ 105.

Ví dụ: dãy 1 3 4 6 8 11, K = 10 → cặp 4 và 6.

Cách 1: thử mọi cặp

for (int i = 0; i < n; i++)
    for (int j = i + 1; j < n; j++)
        if (a[i] + a[j] == K) { cout << a[i] << " " << a[j]; return 0; }

Có khoảng n²/2 cặp, với n = 105 là 5·109 phép so sánh: quá chậm. Hơn nữa cách này chưa dùng đến thông tin quan trọng nhất của đề: dãy đã được sắp xếp.

❓ Hãy nghĩ: giả sử đang xét cặp (số nhỏ nhất, số lớn nhất) mà tổng lớn hơn K. Số lớn nhất kia còn có thể ghép với số nào khác để ra K không?

2. Ý tưởng: hai con trỏ đi từ hai đầu vào giữa

Đặt l = 0 (đầu trái) và r = n − 1 (đầu phải), rồi xét tổng s = a[l] + a[r]:

Trường hợpHành độngLý do
s == KTìm được cặp, dừngĐúng yêu cầu
s < Kl++Tổng đang nhỏ. a[r] đã là số lớn nhất còn lại, ghép với a[l] vẫn thiếu; mà các số ở giữa còn không lớn hơn a[r]. Vậy a[l] không ghép được với ai nữa, bỏ nó.
s > Kr--Tổng đang lớn. a[l] đã là số nhỏ nhất còn lại, ghép với a[r] vẫn thừa. Vậy a[r] không ghép được với ai nữa, bỏ nó.

Mỗi bước loại bỏ chắc chắn một phần tử mà không bỏ sót đáp án. Hai con trỏ gặp nhau thì dừng. Nhờ dãy đã sắp xếp mà ta kết luận được như vậy; đây gọi là tính đơn điệu.

Hình dung với dãy mẫu (vàng là l, xanh là r):

1 + 11 = 12 > 10 nên 11 quá lớn với mọi số (vì 1 đã là nhỏ nhất) → r--.

3. Cài đặt

#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n; long long K;
    cin >> n >> K;
    vector<long long> a(n);
    for (auto &x : a) cin >> x;       // đã sắp xếp tăng

    int l = 0, r = n - 1;
    while (l < r) {
        long long s = a[l] + a[r];
        if (s == K) {
            cout << a[l] << " " << a[r]; return 0;
        } else if (s < K) l++;
        else r--;
    }
    cout << "NO";
}

Độ phức tạp: mỗi vòng lặp làm l tăng hoặc r giảm, nên tối đa n vòng: O(n). Nếu đề cho dãy chưa sắp xếp, hãy sort trước (O(n log n)) rồi mới dùng hai con trỏ.

5. Dạng thứ hai: hai con trỏ cùng chiều (cửa sổ có độ dài thay đổi)

Bài mẫu. Cho dãy n số nguyên dương và số S. Tìm độ dài ngắn nhất của một đoạn liên tiếp có tổng ≥ S (không có thì in 0).
Ví dụ: 2 3 1 2 4 3, S = 7 → 2 (đoạn 4 3)

Ý tưởng. Cả hai con trỏ l, r đều đi từ trái sang phải và không bao giờ lùi. Cửa sổ là đoạn [l, r] với tổng s:

  • Mở rộng: cho r tiến, thêm a[r] vào s.
  • Thu hẹp: khi s ≥ S, ghi nhận độ dài r−l+1, rồi bớt a[l] và l++ để thử đoạn ngắn hơn. Lặp lại chừng nào s ≥ S vẫn đúng.

Vì sao đúng? Các số đều dương, nên thêm phần tử thì tổng tăng, bớt phần tử thì tổng giảm (tính đơn điệu). Khi đoạn [l, r] đã đủ tổng, mọi đoạn bắt đầu từ l mà dài hơn chỉ tệ hơn, nên ta chuyển sang thử l+1. Khi đã thu hẹp đến mức thiếu tổng, ta mới cần mở rộng r.

int l = 0, best = INT_MAX; long long s = 0;
for (int r = 0; r < n; r++) {
    s += a[r];                              // mở rộng
    while (s >= S) {                       // thu hẹp
        best = min(best, r - l + 1);
        s -= a[l]; l++;
    }
}
cout << (best == INT_MAX ? 0 : best);

Độ phức tạp O(n): r đi qua mỗi phần tử một lần, l cũng chỉ tiến, không lùi, nên tổng số lần l++ không vượt quá n (dù có while lồng trong for).

💡 Liên hệ: cửa sổ trượt độ dài cố định chính là trường hợp riêng, khi l và r luôn cách nhau k−1. Hai con trỏ cùng chiều là phiên bản tổng quát: độ dài cửa sổ co giãn theo điều kiện.

6. Bài tập nâng dần

Với mỗi bài hãy tự hỏi: "điều kiện đơn điệu ở đây là gì? Khi nào di chuyển l, khi nào di chuyển r?" Mảng đánh số từ 0.

Bài 1. Gộp hai mảng đã sắp xếp (cơ bản)

Cho mảng a (n số) và b (m số), đều đã sắp xếp tăng. In mảng gộp cũng tăng dần.
Ví dụ: 1 4 7 và 2 3 9 → 1 2 3 4 7 9

Xem lời giải

Hướng dẫn: mỗi mảng một con trỏ (i cho a, j cho b), cùng đi từ đầu. Mỗi lần lấy số nhỏ hơn trong hai số đang chỉ tới rồi tiến con trỏ tương ứng. Khi một mảng hết, chép phần còn lại của mảng kia.

int i = 0, j = 0;
while (i < n && j < m) {
    if (a[i] <= b[j]) cout << a[i++] << " ";
    else cout << b[j++] << " ";
}
while (i < n) cout << a[i++] << " ";
while (j < m) cout << b[j++] << " ";

Độ phức tạp O(n + m). Đây là bước "trộn" trong thuật toán Merge Sort.

Bài 2. Đếm số cặp có tổng bằng K (dễ)

Cho dãy tăng dần gồm n số đôi một khác nhau và K. Đếm số cặp i < j có a[i] + a[j] = K.
Ví dụ: 1 2 3 4 5 6, K = 7 → 3 (các cặp 1+6, 2+5, 3+4)

Xem lời giải

Hướng dẫn: như bài mẫu, nhưng khi tìm thấy cặp thì không dừng: tăng biến đếm và di chuyển cả hai con trỏ (l++, r--). Vì các số khác nhau, cả a[l] lẫn a[r] đều không thể tạo thêm cặp nào khác.

int l = 0, r = n - 1, cnt = 0;
while (l < r) {
    long long s = a[l] + a[r];
    if (s == K) { cnt++; l++; r--; }
    else if (s < K) l++;
    else r--;
}
cout << cnt;

Bài 3. Cặp có tổng gần K nhất (trung bình)

Cho n số (chưa sắp xếp) và K. Tìm tổng của hai phần tử khác vị trí sao cho tổng đó gần K nhất (chênh lệch tuyệt đối nhỏ nhất).
Ví dụ: 10 22 28 29 30 40, K = 54 → 52 (22 + 30)

Xem lời giải

Hướng dẫn: sắp xếp trước, rồi dùng hai con trỏ hai đầu. Ở mỗi bước, cập nhật đáp án nếu |s − K| nhỏ hơn giá trị tốt nhất đã có; sau đó di chuyển con trỏ theo quy tắc cũ (s < K thì l++, ngược lại r--). Không cần dừng khi gặp s == K riêng, vì khi đó chênh lệch bằng 0 và vòng lặp cũng kết thúc đúng.

sort(a.begin(), a.end());
int l = 0, r = n - 1;
long long bestSum = a[0] + a[1];
while (l < r) {
    long long s = a[l] + a[r];
    if (llabs(s - K) < llabs(bestSum - K)) bestSum = s;
    if (s < K) l++; else r--;
}
cout << bestSum;

Bài 4. Đoạn dài nhất có tổng ≤ S (trung bình, cùng chiều)

Cho n số nguyên dương và S. Tìm độ dài lớn nhất của đoạn liên tiếp có tổng không vượt quá S.
Ví dụ: 1 2 3 4 5, S = 9 → 3 (đoạn 2 3 4)

Xem lời giải

Hướng dẫn: đảo vai trò so với bài mẫu. Mở rộng r mỗi bước; nếu tổng vượt S thì thu hẹp l cho đến khi hợp lệ trở lại. Sau khi thu hẹp xong, cửa sổ [l, r] hợp lệ và là đoạn dài nhất kết thúc tại r.

int l = 0, best = 0; long long s = 0;
for (int r = 0; r < n; r++) {
    s += a[r];
    while (s > S) { s -= a[l]; l++; }
    best = max(best, r - l + 1);
}
cout << best;

Nếu a[r] > S thì l vượt qua r, cửa sổ rỗng (s = 0, độ dài 0): code vẫn đúng.

Bài 5. Đoạn dài nhất không có phần tử trùng nhau (khá)

Cho n số nguyên (1 ≤ ai ≤ 105). Tìm độ dài lớn nhất của đoạn liên tiếp mà các phần tử đôi một khác nhau.
Ví dụ: 1 2 3 1 2 5 → 4 (đoạn 3 1 2 5)

Xem lời giải

Hướng dẫn: điều kiện "đoạn hợp lệ" là mỗi giá trị xuất hiện nhiều nhất 1 lần. Dùng mảng cnt[v] đếm số lần v trong cửa sổ. Mỗi khi thêm a[r] mà cnt[a[r]] > 1 (vừa gây trùng), thu hẹp l cho đến khi hết trùng.

vector<int> cnt(100001, 0);
int l = 0, best = 0;
for (int r = 0; r < n; r++) {
    cnt[a[r]]++;
    while (cnt[a[r]] > 1) { cnt[a[l]]--; l++; }
    best = max(best, r - l + 1);
}
cout << best;

Chú ý: đoạn hợp lệ vẫn giữ tính đơn điệu (đoạn con của đoạn không trùng cũng không trùng), nên cách làm này đúng dù không có "tổng".

Bài 6. Bộ ba có tổng bằng K (khó)

Cho n số (chưa sắp xếp) và K. Có tồn tại ba vị trí i < j < k sao cho a[i] + a[j] + a[k] = K không? In YES hoặc NO. (n ≤ 2000)
Ví dụ: 12 3 4 1 6 9, K = 24 → YES (12 + 3 + 9)

Xem lời giải

Hướng dẫn: thử ba vòng lặp thì tốn O(n³). Thay vào đó: sắp xếp, cố định số đầu tiên a[i], rồi bài toán còn lại là "tìm hai số trong đoạn [i+1, n−1] có tổng bằng K − a[i]", đúng là bài mẫu. Tổng cộng O(n²).

sort(a.begin(), a.end());
bool found = false;
for (int i = 0; i < n - 2 && !found; i++) {
    int l = i + 1, r = n - 1;
    while (l < r) {
        long long s = (long long)a[i] + a[l] + a[r];
        if (s == K) { found = true; break; }
        else if (s < K) l++;
        else r--;
    }
}
cout << (found ? "YES" : "NO");

Đây là ví dụ của ý tưởng chung: "cố định bớt một đại lượng để đưa bài toán về dạng đã biết".

7. Lưu ý và lỗi thường gặp

Quên sắp xếp: hai con trỏ hai đầu chỉ đúng khi dãy đã sắp xếp. Nếu sắp xếp mà đề lại hỏi vị trí gốc, hãy lưu kèm chỉ số ban đầu (ví dụ vector<pair<int,int>>).
Dạng cùng chiều cần số không âm: thuật toán thu hẹp/mở rộng dựa vào việc thêm làm tăng tổng. Nếu dãy có số âm, tính đơn điệu bị phá vỡ; khi đó hãy dùng mảng cộng dồn kết hợp map (như Bài 6 của chủ đề mảng cộng dồn).
Điều kiện dừng: hai đầu dùng l < r (không phải <=, vì không ghép phần tử với chính nó).
Quên cập nhật con trỏ: mọi nhánh trong vòng lặp phải làm ít nhất một con trỏ di chuyển, nếu không chương trình lặp vô hạn.
Tràn số: tổng hai hoặc ba số lớn có thể vượt int; dùng long long.
Tóm tắt: hai con trỏ = hai chỉ số đi theo một quy tắc đơn điệu để mỗi lần loại bỏ chắc chắn một phần tử, nên chỉ cần một lượt duyệt O(n).
Hai dạng chính: (1) hai đầu đi vào giữa, trên dãy đã sắp xếp; (2) cùng chiều, cửa sổ co giãn, trên dãy không âm.
