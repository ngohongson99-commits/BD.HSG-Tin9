1. Xâu ký tự là một dãy ký tự

Xâu ký tự (kiểu string trong C++) là một dãy các ký tự viết liền nhau, ví dụ "hello". Nó giống mảng một chiều đã học: mỗi ký tự có một chỉ số bắt đầu từ 0, truy cập bằng s[i], độ dài là s.size().

chỉ số01234
shello

Xâu s = "hello" có độ dài 5, chỉ số hợp lệ từ 0 đến 4 (tức n − 1). s[0] là 'h', s[4] là 'o'.

⚠️ Hai loại dấu nháy: 'a' (nháy đơn) là một ký tự (kiểu char); "a" (nháy kép) là một xâu (kiểu string), dù chỉ có một ký tự.

Điểm khác lớn nhất: string có sẵn rất nhiều thao tác làm việc với văn bản (nối, cắt, tìm xâu con, ...), ta sẽ xem ở mục 3.

2. Khai báo, nhập, xuất và duyệt

Khai báo

#include <iostream>
#include <string>
using namespace std;

string a;                       // xâu rỗng
string b = "hello";             // khởi tạo bằng hằng chuỗi
string c(5, 'x');               // "xxxxx": 5 ký tự 'x'
string d = b + " world";        // nối xâu: "hello world"

Lỗi hay gặp: nếu đọc một số bằng cin >> n; rồi gọi ngay getline(cin, s);, getline sẽ đọc phần còn lại của dòng đầu (chỉ là ký tự xuống dòng) và cho s rỗng. Cần bỏ ký tự xuống dòng thừa trước: 
int n; cin >> n;

string s; getline(cin, s);

Xuất và duyệt

cout << s << "\n";                          // xuất cả xâu
for (int i = 0; i < (int)s.size(); i++) cout << s[i] << " ";   // duyệt theo chỉ số
for (char c : s) cout << c;                  // duyệt từng ký tự (chỉ đọc)
for (char &c : s) c = c + 1;                 // có &: sửa trực tiếp từng ký tự

4. Ký tự là một số nguyên (mã ASCII)

Mỗi ký tự được lưu như một số nguyên nhỏ theo bảng mã ASCII, nên làm được phép tính với ký tự. Ba mốc cần nhớ:

Ký tự'0''A''a'
Mã486597

Các chữ số, chữ hoa và chữ thường nằm liên tiếp trong bảng mã, nên:

Việc cần làmCách viếtVí dụ
Chữ số thành giá trị sốc - '0''7' - '0' = 7
Giá trị số thành chữ số'0' + d'0' + 4 là '4'
Chữ cái thành chỉ số 0 đến 25c - 'a''c' - 'a' = 2 (dùng cho mảng đếm cnt[c - 'a'])
Đổi chữ hoa, chữ thườngtoupper(c), tolower(c)toupper('h') là 'H' (hoa và thường cách nhau 32)
Kiểm tra loại ký tựisdigit(c), isalpha(c), isupper(c), islower(c)isdigit('5') đúng

Các hàm kiểm tra và đổi chữ nằm trong <cctype>. Chú ý: cộng hai ký tự là cộng hai mã số: 'a' + 'b' bằng 195, không phải xâu "ab". Muốn nối ký tự thì dùng s += c.

Về chữ tiếng Việt có dấu: chữ có dấu (ví dụ "ă", "ề") được lưu bằng nhiều byte (UTF-8), nên s.size() đếm số byte chứ không đếm số chữ. Các bài ở đây dùng chữ không dấu (ASCII).

5. Bài toán mẫu: kiểm tra xâu đối xứng

Đề bài. Cho xâu s (không có khoảng trắng, độ dài n ≤ 106). In YES nếu s đối xứng (đọc xuôi và đọc ngược giống nhau), ngược lại NO.
Ví dụ: level → YES; hello → NO

Ý tưởng

Giống bài "mảng đối xứng" ở trang Mảng một chiều: ký tự đầu phải bằng ký tự cuối, ký tự thứ hai bằng ký tự áp chót, ... Tức là với mọi i phải có s[i] == s[n − 1 − i]. Chỉ cần kiểm tra i từ 0 đến n/2 − 1: mỗi cặp đối xứng được xét một lần, ký tự ở giữa (nếu n lẻ) tự bằng chính nó.

#include <iostream>
#include <string>
using namespace std;

int main() {
    string s; cin >> s;
    int n = s.size();
    bool ok = true;
    for (int i = 0; i < n / 2; i++)
        if (s[i] != s[n - 1 - i]) { ok = false; break; }
    cout << (ok ? "YES" : "NO");
}

Cách khác ngắn hơn: tạo xâu đảo ngược rồi so sánh nguyên xâu: string t(s.rbegin(), s.rend()); cout << (s == t ? "YES" : "NO");

Chạy thử

Xâunis[i]s[n−1−i]Kết quả
abcba50aabằng nhau
1bbbằng nhau; n/2 = 2 nên dừng → YES
hello50hokhác nhau → NO ngay

Độ phức tạp: O(n) thời gian, và dừng sớm ngay khi gặp cặp khác nhau. Dùng int n = s.size(); để có số nguyên có dấu (lý do ở mục lưu ý).

6. Bài tập nâng dần

Với mỗi bài hãy tự hỏi: "nhập bằng cin hay getline? Duyệt theo chỉ số hay theo ký tự? Thao tác có sẵn nào của string dùng được?"

Bài 1. Đảo ngược xâu (cơ bản)

Cho một dòng văn bản (có thể có khoảng trắng). In dòng đó theo thứ tự ký tự ngược lại.
Ví dụ: hello world → dlrow olleh

Xem lời giải

Hướng dẫn: vì có khoảng trắng nên đọc cả dòng bằng getline. Dùng reverse của thư viện.

string s; getline(cin, s);
reverse(s.begin(), s.end());          // #include <algorithm>
cout << s;

Kiểm tra: "hello world" đảo ngược ra "dlrow olleh" ✔. Nếu s được đọc sau một lần cin >> n, nhớ cin.ignore().

Bài 2. Đếm nguyên âm, phụ âm, chữ số (dễ)

Cho một dòng văn bản. In ba số: số nguyên âm (a e i o u, cả hoa và thường), số phụ âm (các chữ cái còn lại), số chữ số. Các ký tự khác không tính.
Ví dụ: Hello World 123 → 3 7 3

Xem lời giải

Hướng dẫn: duyệt từng ký tự, phân loại bằng isdigit, isalpha. Với chữ cái, đổi sang chữ thường rồi so với năm nguyên âm.

string s; getline(cin, s);
int v = 0, c = 0, d = 0;
for (char ch : s) {
    if (isdigit(ch)) d++;
    else if (isalpha(ch)) {
        char l = tolower(ch);
        if (l == 'a' || l == 'e' || l == 'i' || l == 'o' || l == 'u') v++;
        else c++;
    }
}
cout << v << " " << c << " " << d;

Kiểm tra: trong Hello World 123 có 10 chữ cái: nguyên âm e, o, o (3), phụ âm H, l, l, W, r, l, d (7), và 3 chữ số ✔.

Bài 3. Đếm số từ (dễ)

Cho một dòng văn bản, các từ cách nhau bởi một hoặc nhiều khoảng trắng (đầu và cuối dòng cũng có thể có khoảng trắng thừa). Đếm số từ.
Ví dụ: " xin chao cac ban " → 4

Xem lời giải

Hướng dẫn: nếu dùng cin >> w liên tiếp, mỗi lần đọc một từ và tự bỏ qua mọi khoảng trắng thừa. Có thể đọc từ chuỗi bằng istringstream (thư viện <sstream>) để đọc từng từ trong một dòng đã có sẵn.

string s; getline(cin, s);
istringstream iss(s);
string w; int dem = 0;
while (iss >> w) dem++;
cout << dem;

Kiểm tra: bỏ qua khoảng trắng thừa, đọc được xin, chao, cac, ban → 4 ✔. (Cách tự đếm: một "từ mới" bắt đầu ở ký tự không phải khoảng trắng mà ký tự đứng ngay trước nó là khoảng trắng hoặc không có.)

Bài 4. Chuẩn hóa họ tên (trung bình)

Cho một dòng họ tên (không dấu) có thể thừa khoảng trắng và hoa thường lộn xộn. In ra họ tên chuẩn: mỗi từ viết hoa chữ cái đầu, các chữ còn lại viết thường, các từ cách nhau đúng một khoảng trắng, không có khoảng trắng ở đầu và cuối.
Ví dụ: " nGUYEN van an " → Nguyen Van An

Xem lời giải

Hướng dẫn: tách từng từ bằng istringstream (như bài 3). Với mỗi từ: đổi hết sang chữ thường, rồi đổi chữ đầu thành chữ hoa. Nối vào kết quả, thêm một dấu cách trước mỗi từ trừ từ đầu tiên.

string s; getline(cin, s);
istringstream iss(s);
string w, kq;
while (iss >> w) {
    for (char &c : w) c = tolower(c);
    w[0] = toupper(w[0]);
    if (!kq.empty()) kq += " ";
    kq += w;
}
cout << kq;

Kiểm tra: các từ nGUYEN, van, an thành Nguyen, Van, An rồi nối bằng một dấu cách ✔.

Bài 5. Cộng hai số rất lớn (khá)

Cho hai số nguyên không âm, mỗi số có tới 105 chữ số, cho dưới dạng xâu. In tổng của chúng.
Ví dụ: 99999 và 1 → 100000

Xem lời giải

Hướng dẫn: số quá lớn nên không lưu được vào long long; ta cộng bằng tay như ở tiểu học. Đi từ chữ số cuối về đầu của cả hai xâu, cộng hai chữ số cùng hàng và số nhớ (carry), ghi chữ số hàng đơn vị của tổng, nhớ phần chục. Tiếp tục đến khi hết cả hai xâu và hết nhớ. Kết quả ghi theo thứ tự ngược nên cuối cùng đảo lại.

string a, b; cin >> a >> b;
string r;
int i = a.size() - 1, j = b.size() - 1, nho = 0;
while (i >= 0 || j >= 0 || nho) {
    int t = nho;
    if (i >= 0) t += a[i--] - '0';       // chữ số thành giá trị
    if (j >= 0) t += b[j--] - '0';
    r.push_back('0' + t % 10);               // giá trị thành chữ số
    nho = t / 10;
}
reverse(r.begin(), r.end());
cout << r;

Chạy thử 99999 + 1: từ phải sang trái được 9+1=10 (ghi 0, nhớ 1), rồi bốn lần 9 + nhớ 1 = 10 (ghi 0, nhớ 1), cuối cùng còn nhớ 1 (ghi 1) → ghi ngược 000001, đảo lại 100000 ✔. Độ phức tạp O(độ dài). Bài này dùng cả c - '0' lẫn '0' + d ở mục 4.

Bài 6. Đối xứng sau khi xóa tối đa một ký tự (khó)

Cho xâu s (độ dài n ≤ 106). Có thể xóa tối đa một ký tự (hoặc không xóa) để xâu còn lại đối xứng không? In YES/NO.
Ví dụ: abca → YES (xóa c được aba); abc → NO

Xem lời giải

Hướng dẫn: thử xóa từng ký tự rồi kiểm tra đối xứng thì tốn O(n²). Dùng hai con trỏ từ hai đầu vào giữa như bài mẫu: khi s[l] == s[r] thì thu hẹp. Lần đầu gặp cặp khác nhau, ta buộc phải xóa một trong hai ký tự đó: xóa s[l] (kiểm tra đoạn [l+1, r] có đối xứng không) hoặc xóa s[r] (đoạn [l, r−1]). Nếu một trong hai đoạn đối xứng thì YES. Chỉ cần thử hai khả năng này, không phải thử mọi vị trí.

bool doiXung(const string &s, int l, int r) {
    while (l < r) {
        if (s[l] != s[r]) return false;
        l++; r--;
    }
    return true;
}

// trong main
int l = 0, r = s.size() - 1; bool ok = true;
while (l < r) {
    if (s[l] == s[r]) { l++; r--; }
    else { ok = doiXung(s, l + 1, r) || doiXung(s, l, r - 1); break; }
}
cout << (ok ? "YES" : "NO");

Chạy thử abca: a = a thu hẹp về l=1, r=2; b ≠ c: thử xóa b (đoạn "c" đối xứng) → YES. Với abc: a ≠ c, đoạn "bc" và "ab" đều không đối xứng → NO ✔. Độ phức tạp O(n).

7. Lưu ý và lỗi thường gặp

getline sau cin >>: phải gọi cin.ignore() trước, nếu không getline trả về xâu rỗng (xem mục 2).
s.size() là số không dấu: nếu s rỗng thì s.size() - 1 không bằng -1 mà là một số cực lớn, và i < s.size() - 1 có thể chạy sai. Hãy lưu int n = s.size(); rồi dùng n.
Truy cập ngoài phạm vi: s[i] chỉ hợp lệ với 0 ≤ i < n. Truy cập s[n] hoặc s[-1] là lỗi (có thể không báo ngay).
Nhầm 'a' với "a": nháy đơn là ký tự, nháy kép là xâu. 'a' + 'b' cộng hai mã số (195), không nối xâu; muốn nối dùng s += c hoặc s + t với ít nhất một vế là string.
find không thấy: trả về string::npos, không phải -1 thông thường. So sánh bằng == string::npos.
Chèn hoặc xóa ở đầu/giữa trong vòng lặp: s.insert(0, ...), s.erase(i, 1) tốn O(n) mỗi lần, dùng trong vòng lặp thành O(n²). Thêm vào cuối (s += c) thì nhanh. Nếu cần chèn đầu, hãy xây xâu ngược rồi reverse một lần (như bài 5).
Chữ tiếng Việt có dấu: s.size() đếm byte, không đếm chữ; các bài tập chỉ dùng chữ không dấu.
Tóm tắt: string là dãy ký tự đánh số từ 0 (s[i], s.size()), nhập một từ bằng cin, cả dòng bằng getline. Có sẵn substr, find, insert, erase, +, so sánh, reverse, sort. Ký tự là số (mã ASCII): c - '0', c - 'a', tolower, toupper. Kỹ thuật hai đầu (s[i] với s[n−1−i]) giống mảng đối xứng.
Chủ đề tiếp theo: Xử lý xâu cơ bản (tách từ, anagram, đếm tần suất ký tự).
